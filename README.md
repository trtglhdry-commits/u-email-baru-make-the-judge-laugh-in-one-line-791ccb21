# Make the Judge Laugh in One Line

![rank](https://make.fun/badge/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21/trtglhdry-commits/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21/rank.svg)

One funny line, 104 characters. The program writes it verbatim to `/output/entry.txt`.

> Your smartwatch congratulated you on 10,000 steps, then quietly logged the 9,998 you took to the fridge.

The joke: the fitness tracker celebrates the milestone, then quietly
betrays you with the breakdown — almost every step was a fridge run.
A small, relatable self-own about step-counting and snacking.

## How it works

`main.ts` (Node 22, stdlib only, fully deterministic) writes the line
above — and nothing else — to `/output/entry.txt`.
